# Career Description Skills

공개 채용 공고와 공식 직무·작성 자료를 조사해 한국어 팀장급 경력기술서를 작성·검토하는 스킬이다. **직접 책임지는 산출물을 기준으로 12개 기능을 분류**하고, **왜 일이 필요했고, 왜 그 판단을 했으며, 결과가 왜 의미 있는지**를 확인된 경력으로 설명한다.

## 포함된 스킬

[write-career-description](skills/write-career-description/SKILL.md)는 지원 요건에 맞는 과제와 정기 운영 경험을 고르고, 책임·판단·행동·성과를 확인된 경력으로 설명한다. 관리자뿐 아니라 직무 전문 리드나 팀장 승진 지원자의 경험도 실제 권한 범위 안에서 작성한다. 결산·영업 실적 관리·채용 운영·생산라인 관리도 그 업무의 단위와 기간으로 설명한다.

```text
$write-career-description 스킬로 이 채용 공고와 경력 자료를 대조해
팀장급 경력기술서를 작성해 줘. 회사 지정 양식을 지키고,
직무에 맞는 성과 지표와 본인 역할·의사결정·팀 성과가 드러나게 써 줘.
새로운 직무는 해당 직무를 조사하고, 필요성과 선택 이유를 근거로 연결해 줘.
```

## 책임 기준 직무 분류

주분류의 축은 **직접 책임지는 산출물의 목적과 대상**이다. 산업, 기술·AI·AX, 기획·운영 단계, 사람관리 여부는 별도 속성으로 기록한다. 복합 직책은 책임 단위로 나누고 각 단위에 주분류 하나를 부여한다. 대표 기능은 주된 책무가 확인될 때만 정한다.

| 코드·기능 | 직접 책임지는 결과의 예 |
| --- | --- |
| F01 사업경영·전략 | 사업 방향·포트폴리오·자원 우선순위·통합 실행 |
| F02 제품·서비스·연구개발 | 제공 가치·제품 사양·UX·새 지식·기술·제품 기능 |
| F03 마케팅·커뮤니케이션 | 시장 인식·수요·브랜드·캠페인·대외 소통 |
| F04 영업·거래개발 | 판매·제휴·갱신의 거래조건과 계약 성사 |
| F05 고객지원·활용 | 이미 제공한 제품·서비스의 도입·사용·고객 문제 해결 |
| F06 구매·공급망·물류 | 외부 자원 조달·수급·재고·운송·배송 |
| F07 생산·시공·서비스 제공 | 재화 생산·시공·진료·교육 등 현장·전문 서비스 이행 |
| F08 인사·조직역량 | 고용·평가·보상·조직·사내 역량 체계 |
| F09 재무·회계·자본 | 결산·예산·전망·자금·자본·재무 보고 |
| F10 정보시스템·데이터 서비스 | 공통 디지털 업무기반·데이터 서비스의 공급·성능·가용성 |
| F11 시설·자산·행정지원 | 자기 조직의 물리적 업무기반·시설·자산·공용 사무 |
| F12 법무·위험·보증 | 법적 판단·준법·위험·보호 통제·적합성 판정·독립 검증 |

각 기능의 포함·제외 조건과 경계 판정은 [책임 기준 직무 분류](skills/write-career-description/references/job-taxonomy.md)에 있다. 예를 들어 CRM 캠페인은 F03, CRM 시스템 기반은 F10이다. 고객 활용 지원은 F05, 갱신 계약 성사는 F04다. 규격품 생산은 F07, 별도 적합성 판정은 F12다. F10에도 개발이 있고 F02에도 출시 후 운영·개선이 있으므로 개발/운영 단계로 자동 배정하지 않는다.

MECE는 **기업·기관의 사업 수행·조직 지원·보증 책임을 중복 없이 배정하고 입력 책임을 빠짐없이 점검하는 규칙**으로 적용한다. 정보 부족과 범위 밖을 별도로 남기며 이를 임의의 기타·운영·IT 직무로 넣지 않는다. 같은 프로젝트를 여러 책임으로 나누어도 동일 성과를 다시 합산하지 않는다. 직함·분류 코드로 인사권을 추정하지 않는다.

## 신규 직무와 설명의 완성 기준

스킬에 없는 직무·전문 분야는 **그 직무 자체를 조사해 작성 기준을 보강**한다. 같은 기능에 속해도 간호·교육·시공·숙박의 책임과 성과 기준은 다르다. 직무명과 실제 책임을 특정하고 공식 공고·기관 역할 자료에서 목적, 판단, 산출물, 권한, 성과 확인 기준을 확보한다. 새 이름이라는 이유로 미확정·범위 밖에 두지 않는다.

이번 보강에는 식품 R&D, 간호, 교육, 시공, 시설, 총무, 법무, 산업안전, 환경, 객실 운영, 식음료, 농축산, 예방보존의 13개 사례를 추가했다. 자료에 없는 다른 직무도 같은 조사 절차를 적용한다. 공고의 상태·직급·지역과 실제 읽은 범위는 각 사례에 기록했다.

핵심 경력은 **필요성·맥락 → 선택 기준과 본인 행동 → 확인된 결과와 의미**를 연결한다. 독자가 ‘왜?’라고 물을 지점을 검수하고, 후보자의 기존 자료·진술에서 답을 찾는다. 외부 직무 자료는 확인할 질문을 정하는 근거이며 후보자의 실제 선택 이유를 대신하지 않는다. 개인 사실이 빠졌다면 그 사실만 확인하며 작성 가능한 본문은 먼저 완성한다.

## 사용

Agent Skills를 지원하는 환경의 개인 스킬 경로에 `skills/write-career-description` 폴더 전체를 설치한다. `SKILL.md`와 참조자료를 함께 유지한다. 설치 경로와 활성화 방식은 사용하는 클라이언트의 지침을 따른다. ChatGPT 개인 스킬은 해당 환경의 skill-creator 절차로 설치한다.

입력은 목표 공고, 경력 자료, 제출 양식이 기본이다. 공고가 없으면 목표 역할을 기준으로 범용 초안을 만들 수 있다. 문서 파일을 요청할 때는 해당 환경의 DOCX/PDF 생성 도구를 함께 사용한다.

한국어 편집은 [ContextualWisdomLab/korean-writing-skills](https://github.com/ContextualWisdomLab/korean-writing-skills)의 korean-editing과 함께 사용할 수 있다. 설치되어 있지 않아도 이 스킬의 기본 편집·검수 절차를 적용할 수 있다. 다른 스킬이나 코드를 자동 다운로드·실행하지 않는다.

## 근거 범위

조사 기준일은 **2026-11-08, Asia/Seoul**이다. 공개 채용 공고는 요구사항을 보여 주는 사례다. 실제 합격자의 경력기술서, 채용 성공률 또는 특정 형식의 효과를 입증하는 자료로 취급하지 않는다. 상세 열람 범위와 날짜는 채용 조사 파일에 기록했다. 마감된 공고, 해외 사례, 과거 직무자료, 인사관리 책임이 확인되지 않은 전문 역할은 각각 구분한다. 목록에 없는 직무·전문 분야를 받으면 그 요청에서 자료를 추가 조사해 작성 기준에 반영한다.

12개 기능은 경력기술서 작성을 위한 자체 분류다. ILO의 실제 과업·책무에 관한 개념을 참고했으며, ISCO·NCS 코드의 복제나 공식 인증 분류가 아니다. 실제 조직의 모든 직책이 한 기능에만 속하거나 미확인 책임까지 자동 판정된다고 주장하지 않는다.

기간 중복 제거, 역할 구분, 내부 근거표, 문서 구성은 이 저장소의 편집·검증 설계다. 이를 모든 회사의 의무 기준으로 확대하지 않는다. 고정 쪽수·ATS 점수·합격률을 보장하지 않는다.

## 후보자 자료

예시와 평가 입력은 모두 합성 자료다. 실제 이력서, 연락처, 보상, 비공개 프로젝트·고객 자료를 이 저장소에 추가하지 않는다. 문서 작성은 지원서 전송이나 포트폴리오 공개를 포함하지 않는다.
