# 적용 검증 기록

이 문서는 최초 버전의 A~C 실행 기록이다. 직무 확장 이후의 변경과 D~G 실행은 [직무 확장 검증](role-expansion.md)에 따로 기록한다. 아래 SHA와 관찰 결과를 새 버전에서 재실행한 결과로 해석하지 않는다.

실행일: 2026-11-08. 입력은 [합성 사례](cases.md), 관찰 결과는 [출력 원문](observed-outputs.md)에 있다. 작성자는 각각 새 대화에서 작업했고 기대 정답이나 다른 실행의 결과를 보지 않았다. 평가자는 반환된 전체 출력을 직접 읽고 아래 항목을 대조했다.

검증한 SKILL.md SHA-256: `8a867184f8d78088fa5bbacee6aaaf63c9dab71064e975ffc082d4957150d11a`.

## 기준 실행

새 스킬 없이 사례 A를 한 번 실행했다. 기간·수치·권한은 정확하게 유지했다. 이를 사실성 실패로 기록하지 않는다. 개선할 점은 동일 사례의 상세 반복, 제출 문서 속 검수 해설, 지원 요건과의 차이를 별도 메모로 명시하지 않은 부분이었다.

## 스킬 적용 실행

| 관찰 항목 | 사례 A | 사례 B |
| --- | --- | --- |
| 경력 기간 | 116개월, 약 9년 8개월. 자문 중복 가산 없음 | 154개월, 약 12년 10개월. 사람관리 약 4년 10개월 |
| 역할·권한 | 8명 참여 프로젝트와 본인 담당 구분. 인사권 생성 없음 | 직속 6명 관리·성과평가를 명시. 본부장 채용 결정·CFO 예산 승인 구분 |
| 팀 결과·개인 행동 | PR 검토 기준과 팀 배포 간격을 구분 | 본인의 현업·기준 설계와 개발팀 구현을 구분 |
| 수치 | 14→9일, 5일·35.7% 감소를 정확히 제시 | 5→3일, 8→5%를 원자료대로 유지 |
| 적용 범위 | 6개 서비스·3개월 조건 유지 | 2개 부서·40명·각 4주 200건·전후 비교 조건 유지 |
| 예상·실제 | 해당 없음 | 연 2억원은 전사 확대 예상치, 확대 승인 전으로 유지 |
| 지정 항목 | 요구한 3개 절 유지 | 요구한 3개 절 유지 |
| 분량 | 별도 제한 없음 | 본문 264자·274자·132자. 공백 포함, 제목 제외, 각 500자 이하 |
| 별도 메모 | 10년 요건과의 약 4개월 차이를 별도 표시 | 요건과 자료의 주요 충돌 없음 |

수치와 문자 수는 별도 계산으로 대조했다. 사례 A·B에서 관찰한 사실·권한·지표·예상 효과·지정 형식 항목은 충족했다. 사례 A는 설계 검토와 온보딩 표현의 반복이 일부 남아 있어 최종 문장 압축은 여전히 필요하다.

## 새로운 입력에 대한 추가 적용

사례 A의 최초 실행 당시 참조자료의 설명 예시에 A와 같은 기간·수치가 일부 포함돼 있었다. 따라서 A를 독립적인 일반화 검증으로 보지 않는다. 설명 예시를 다른 기간·수치로 바꾼 후, 해당 값이 예시에 없는 사례 C를 새 작성자에게 전달했다. SKILL.md 본문은 변경하지 않았다.

| 관찰 항목 | 사례 C |
| --- | --- |
| 기간·요건 | 병행 자문을 더하지 않고 약 10년으로 작성. 12년 요건과의 차이를 별도 메모에 명시 |
| 역할·권한 | 10명 프로젝트에서 ETL 설계·코드리뷰·3명 온보딩을 담당한 범위로 작성. 최종 결정은 기술위원회로 유지 |
| 수치·귀속 | 동일 90개 작업·전후 각 4주·중앙값 20→15분·25% 감소를 유지. 동료의 하드웨어 최적화를 포함하는 공동 성과로 설명 |
| 예상·실제 | 연 1억원 예상 절감은 실현 성과에서 제외하고 별도 메모로 설명 |
| 누락 경험 | 제공하지 않은 일정 조율 경험을 만들어 내지 않음 |
| 분량·구성 | 본문 456자(공백·줄바꿈 포함, 제목 제외). 1,000자 이내이며 작성 기준을 본문과 분리 |

C의 월 단위 경력은 120개월이며 감소율은 `(20 - 15) / 20 × 100 = 25%`다. 독립 계산으로 대조했다. C에서도 관찰 항목을 충족했지만, 이 단일 추가 실행은 폭넓은 일반화 성능이나 과장 방지의 완전성을 입증하지 않는다.

## 구조 검증

- 공식 skill-creator의 `quick_validate.py`: 통과.
- SKILL.md에서 참조한 상대 경로 및 참조자료 내부의 상대 링크: 파일 존재 확인.
- UI 메타데이터: 스킬 이름을 포함한 기본 프롬프트와 한국어 표시명 확인.
- 실제 후보자 자료 대신 합성 입력만 사용.

## 수행하지 않은 검증

이번 배포는 스킬과 연구·평가 자료다. 실제 지원자의 경력 사실 확인, DOCX/PDF 생성·렌더링, 특정 ATS 업로드, 채용 결과 검증은 수행하지 않았다. 소수 합성 실행의 관찰을 전반적인 성능 향상·합격률·통계적 타당화로 해석하지 않는다.
