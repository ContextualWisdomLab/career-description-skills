# 경력기술서 구성

이 파일은 작성자가 참고하는 구성안이다. 아래 설명·괄호·미작성 항목은 완성 제출본에서 제거한다. 제출처의 지정 양식이 있으면 그 양식이 우선한다.

## 1. 경력 요약

전문 영역, 실제 경력 기간, 대표적인 책임과 확인된 강점을 3~5문장 안에서 연결한다. 분량은 편집상 출발점이며 필수 규격이 아니다. 목표 직함을 현재 직함으로 쓰지 않는다.

## 2. 회사별 경력

회사명 / 재직 기간 / 공식 직함을 표시하고 조직 내 역할·책임을 간결히 적는다. 최근 경력부터 일관되게 배치한다. 자문·겸직은 병행 여부를 보존한다. 초기 경력도 요건이나 전문성을 뒷받침하면 남긴다.

## 3. 주요 경험과 성과

지원 요건과 가장 가까운 경험부터 고른다. 각 사례는 다음 정보를 필요한 범위에서 포함한다.

- 프로젝트·과제 또는 정기 운영 업무와 기간
- 업무·사업 맥락, 해결해야 했던 문제
- 본인 역할, 팀·협업 범위, 의사결정권
- 핵심 판단과 행동, 선택의 이유
- 확인된 결과·산출물, 측정 기간·범위

하나의 경험은 이 절 또는 회사별 경력의 하위 항목 중 한 곳에서만 상세히 설명한다. 결산, 분기 영업, 채용 운영, 생산라인 관리처럼 반복되는 업무는 운영 대상·기간·관리 기준·개선 결과로 구성한다. 모든 경험을 출시·개발 프로젝트로 바꾸지 않는다. 경험이 적으면 별도 성과 절을 늘리지 않아도 된다. 확인되지 않은 배경·성과는 형식을 채우기 위해 만들지 않는다.

## 4. 직무 전문성·도구·자격·학력

요청되거나 직무 판단에 필요한 항목을 정확한 명칭·상태·시점으로 제시한다. 전문 방법·도구는 실제 적용 경험과 연결한다. 직무상 필요한 자격·면허는 실제 취득·유효 상태를 확인하며 교육 이수로 대체하지 않는다. 자기소개서·이직 사유·입사 후 계획은 요청된 경우 해당 문항에 따로 쓴다.

## 별도 사용자 검토 메모

제출용 본문 밖에 지원 요건 차이, 상충하는 사실, 미실시 파일 검증만 짧게 적는다. 모든 경력에 확인 표지를 붙이거나 일반적인 주의사항을 길게 나열하지 않는다.
