## 1. 조사 범위

팀장급 경력기술서의 책임과 근거를 설명할 때 참고할 공개 공고, 공식 직무자료와 경력 작성 지침을 선별했다. 현재 직무 배정은 [책임 기준 12개 기능](job-taxonomy.md)을 따른다. 새 직무·전문 분야가 등장하면 [조사 절차](research-and-reasoning.md)로 해당 직무의 목적·판단·산출물을 직접 조사해 작성 기준을 보강한다. 이 목록에 없다는 이유로 미확정 상태에 두지 않는다. 채용 요구사항·책임을 조사한 것으로 실제 합격자의 서류나 채용 결과 연구가 아니며 시장 전체를 대표하는 통계 표본도 아니다.

모든 아래 출처의 확인일은 2026-11-08이다. 정확한 게시·마감일이 본문에 없으면 미표시로 기록했다. 검색엔진의 크롤링 날짜를 게시일로 바꾸지 않았다. 지원 링크의 존재는 접수 성공이나 잔여 채용 인원을 검증한 것이 아니다. 공고를 실제 지원에 사용할 때는 최신 원문과 제출 조건을 다시 확인한다.

## 2. 채용·직무 사례와 확인 범위

H01~H04는 기업 채용사이트 상세 원문을 확인했다. H05는 원티드 게재 공고, H06은 기업의 공고 목록과 고용24에 연계된 원티드 본문을 확인했다. 추가 사례도 아래에 기업 원문·공식 ATS·과거 직무자료 여부와 국내외 범위를 기록한다. 초기 여섯 사례 중 네 건이 토스 계열사였던 편중을 넓혔지만, 통계적 대표 표본은 아니다. 전문 역할 비교를 포함하므로 모든 사례를 직속 인사관리가 명시된 팀장 채용으로 세지 않는다.

채용·직무 사례는 H01~H15 **15건**과 [추가 직무 조사](expanded-role-research.md)의 N01~N13 **13건**, 합계 **28건**이다. R01은 사람관리 여부를 구분하기 위한 별도 비교 공고다. H10은 과거 영국 직무자료, H11은 글로벌 역할 정의, H15는 중국 공고다. H12·H13은 국내 채용 플랫폼 본문을 확인했다. 추가 조사에는 국내 기관·기업, 해외 공식 공고와 정부 채용포털이 포함되며 마감·직급·열람 범위를 건별로 기록했다.

아래 표는 공고 안의 관련 책임과 자료를 연결한다. 공고 전체를 하나의 책임으로 보거나 여러 주분류를 중복 부여한 표가 아니다. 실제 작성 때는 공고·경력을 책임 단위로 나누어 하나씩 배정한다.

USAJOBS의 과거 경력 작성 안내 URL은 재확인 시 도움말 메인으로 이동했다. 세부 본문을 이 조사에서 재확인하지 못해 규칙 근거에서 제외했다. 해외 채용의 페이지 제한·직급 코드 등을 한국 경력기술서의 필수 항목으로 가져오지 않는다.

실제 합격률, 최적 쪽수, 관리자 공통 최소 경력, 보편적인 ATS 점수는 이 자료로 입증하지 않는다. 확인된 여러 공고에서 읽어 낸 공통점은 적용 판단이며 시장 전체에 대한 통계적 결론이 아니다.
