## 4. 조사 결과의 사용

위 사례마다 해당 직무의 존재 목적·직접 산출물·판단·권한과 작성 질문을 마련했다. 날짜나 특정 권한이 표시되지 않은 것은 해당 항목의 확인 한계이며 직무 자체를 미조사로 남기는 근거가 아니다. 자료에 없는 세부 직무를 받으면 [신규 직무 조사 절차](research-and-reasoning.md)를 실행한다.

마감된 공고도 책임의 역사적 사례로 사용할 수 있지만 현재 지원 요건으로 제시하지 않는다. 지원 버튼이 있다는 사실만으로 실제 접수 상태를 보장하지 않으며, 공개 공고를 합격 사례나 문서 효과의 증거로 쓰지 않는다.

검색에서 발견한 Natural History Museum의 Head of Preventive Conservation PDF 링크는 열람 시 다른 직무인 Innovation Unit Administrator로 이동하여 해당 역할의 근거에서 제외했다. 원문 제목과 본문이 일치하는지 확인한 자료만 역할 카드에 사용했다.
